# Morph Everything — мод для Minecraft 1.21.4 (Forge)

Важно: этот проект **ещё ни разу не компилировался и не запускался в игре**. Я писал код по документации Forge, но проверить его без интернета и без Minecraft не мог. Поэтому при первой сборке возможны ошибки компиляции. Это нормально: пришлёшь мне текст ошибки, я исправлю код, и ты соберёшь заново.

## Как получить готовый .jar (без программирования)

Сборку выполнит бесплатный сервер GitHub.

1. Зарегистрируйся на https://github.com (бесплатно, около 5 минут).
2. Нажми «+» справа вверху, затем **New repository**. Назови `morph-everything`, выбери **Public**, нажми **Create repository**.
3. Распакуй этот ZIP на компьютере. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Перетащи в окно **всё содержимое распакованной папки**: `build.gradle`, `settings.gradle`, `gradle.properties`, папку `src` и папку `.github`.
   - Папка `.github` скрытая. В Windows: Проводник → Вид → Показать → **Скрытые элементы**. На Mac: Cmd+Shift+точка.
   - Если `.github` не загрузилась: **Add file → Create new file**, в имени файла впиши `.github/workflows/build.yml` и вставь туда содержимое файла `build.yml` из архива.
5. Внизу нажми **Commit changes**.
6. Открой вкладку **Actions**. Сборка стартует сама, первый раз 5–10 минут.
   - Зелёная галочка: сборка успешна. Открой запуск, внизу в разделе **Artifacts** скачай `morpheverything-jar`. Внутри ZIP лежит `morpheverything-1.0.0.jar`.
   - Красный крестик: открой запуск, нажми на шаг **Build**, скопируй текст ошибки (последние ~50 строк) и пришли мне.

## Установка

1. Установи Minecraft Forge для 1.21.4 (версия 54.1.0 или новее 54.x) с https://files.minecraftforge.net/net/minecraftforge/forge/index_1.21.4.html — установщик, пункт «Install client». Нужна Java 21 (обычно уже есть вместе с игрой).
2. Положи `morpheverything-1.0.0.jar` в папку `mods` (Win+R → `%appdata%\.minecraft\mods`; если папки нет, создай).
3. В лаунчере выбери профиль Forge 1.21.4 и запусти игру.

На сервере мод должен стоять и на сервере, и у всех игроков.

## Управление (клавиши меняются в Настройки → Управление → Morph Everything)

| Клавиша | Действие |
|---|---|
| M | Меню превращений (Esc или M закрывает) |
| N | Вернуться в обычный вид |
| B | Следующая из последних форм |
| R | Способность формы (телепорт Эндермена, взрыв Крипера) |

В меню: ЛКМ по иконке — превратиться; ПКМ или Shift+ЛКМ — добавить в избранное; сверху поиск и категории.

## Что реализовано

- Превращение в любого «живого» моба из реестра игры (включая Эндер-дракона, Иссушителя и мобов из других модов) и в блоки с обычной моделью. Внешний вид меняется настоящей отрисовкой, другие игроки тоже видят твою форму.
- Ты остаёшься настоящим игроком: управление, инвентарь, взаимодействие с миром сохраняются.
- Хитбокс подстраивается под высоту формы (не больше `maxScale` из конфига).
- Меню с поиском, категориями (Все, Избранное, Недавние, Животные, Монстры, Жители, Боссы, Блоки, Другое), иконками, избранным и кнопкой сброса.
- Формы открываются убийством моба или добычей блока (настраивается); можно открыть всё сразу (`unlockAll`). Открытые формы, избранное и недавние сохраняются в данных игрока.
- Сервер сам проверяет каждый запрос: форма существует, не в чёрном списке, открыта у игрока.
- Способности: полёт у летающих мобов (летучая мышь, пчела, попугай, аллей, вексы, гаст, фантом, ифрит, дракон, иссушитель), подводное дыхание и скорость плавания у водных мобов, огнестойкость у огнеупорных мобов, телепорт Эндермена, взрыв Крипера (по умолчанию выключен, включается в конфиге).

## Чего пока НЕТ (честно)

- Нет специальных способностей остальных мобов (лазание паука, стрельба скелета и т. д.).
- Блоки с особой отрисовкой (сундуки, кровати, таблички, жидкости) в список форм не попадают.
- Хитбокс масштабируется по высоте, поэтому ширина у «толстых» и «тонких» мобов лишь приблизительная. Для блока хитбокс примерно 0,33×1,0.
- Рука от первого лица остаётся рукой игрока.
- Мобы из других модов с нестандартной отрисовкой могут выглядеть неправильно.
- Не проверено в игре, не проверено на выделенном сервере.

## Настройки

Файл `config/morpheverything-common.toml` (появляется после первого запуска): `unlockAll`, `unlockOnKill`, `unlockOnBreak`, `allowMobs`, `allowBlocks`, `maxScale`, `blacklist`, `allowFlight`, `waterAbilities`, `fireImmunity`, `endermanTeleport`, `creeperExplosion`, `creeperExplosionBreaksBlocks`.
